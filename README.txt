CONTACT AND REGISTRATION SETUP
Both forms use FormSubmit and send to qabas.club@univ-mosta.dz. On the first submission, FormSubmit normally sends a confirmation email to that inbox; the inbox owner must confirm it before submissions are delivered. Test using a real web host or local web server, not by opening the file directly with file://.

IMPORTANT ADMIN DASHBOARD NOTE
A secure admin dashboard that stores and displays private messages/registrations needs a backend/database and authentication. This static HTML package deliberately does not pretend to provide secure private admin access or store student submissions in the browser. Connect a backend (for example Supabase/Firebase or a university server) before adding private admin message management.

EVENT DATES
The pre-existing sample event cards may contain placeholder dates. Confirm real dates/venues with QABAS before publishing them as upcoming events.
